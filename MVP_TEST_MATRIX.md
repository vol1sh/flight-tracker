# Flight Tracker — матрица приёмочного тестирования MVP
- `PASS` — тест проведён, фактический результат соответствует ожидаемому.
- `FAIL` — тест проведён, ожидаемое и фактическое поведение различаются; ссылка на баг обязательна.
- `BLOCKED` — тест сейчас нельзя выполнить (нет действительного доступа к AviationStack, данных, конфигурации и т.д.); записать причину.
- `NOT RUN` — тест не выполнялся.
